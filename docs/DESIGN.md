# עיצוב

## כיוון

נקי, אוורירי וכיפי, בהשראת הרוח של אתר "מתכונים ב-10 דקות" (רקע לבן, צבע ראשי אחד בולט, תמונות גדולות, חיפוש בולט, סינונים מהירים). מהזהות שלהם לא לוקחים כלום: הצבעים, הלוגו והגופן הם של קרן.

## צבעים (מהלוגו)

| שימוש | ערך |
|---|---|
| ירוק מרווה (הלוגו) | `#6f8f79` |
| ירוק עמוק לכפתורים וטקסט על לבן (ניגודיות AA) | `#4a6b56` |
| ירוק כהה לכותרות ופוטר | `#2f4a3a` |
| שמנת (הלוגו) | `#f7f5ef` |
| שחור (הלוגו) | `#1f1f1f` |
| חמאה, להדגשות קטנות | `#f6dd8f` |
| אלמוג, ללב "שמרתי" בלבד | `#e2604d` |

כל הצבעים מוגדרים כמשתנים בראש `css/styles.css`.

## גופנים

- **Rubik**: כותרות וטקסט. עגול וידידותי.
- **Playpen Sans Hebrew**: כתב יד, רק לתוויות קטנות ולשורות "מהלב" (לא לפסקאות).

## לוגו

`assets/logo/`: `logo-mark-*` (הסהר עם האוזן), `logo-word-*` (הכיתוב "Wolf"), `logo-full-*` (שניהם), בירוק, בשמנת ובשחור. `original-*` הם הקבצים כפי שנמסרו. לא משנים צבעים, פרופורציות או מרווחים.

## עקרונות

- צבע ראשי אחד (ירוק מרווה). שאר הצבעים רק כהדגשה קטנה.
- צורת הקשת חוזרת בתמונות, בהשראת הסהר שבלוגו.
- כל אינטראקציה נשארת אופציונלית: אפשר להשתמש באתר בלי מועדפים, טיימרים או מצב בישול.
- תנועה עדינה בלבד, ומכובדת ב-`prefers-reduced-motion`.
